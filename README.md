# HIITime Support

**HIITime** is a HIIT workout timer for iPhone and Apple Watch.

## Getting Support

If you need help, have a feature request, or want to report a bug, please [open a GitHub Issue](https://github.com/pantry-org/HIITime-Support/issues/new/choose).

### Before opening an issue

- Check the [existing issues](https://github.com/pantry-org/HIITime-Support/issues) to see if your question has already been answered.

### What to include in a bug report

- Your iPhone model and iOS version
- Your Apple Watch model and watchOS version (if applicable)
- A description of what happened and what you expected to happen
- Steps to reproduce the issue
